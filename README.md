# 北京国管公积金贷款提前还款规划器

一个手机优先、纯前端的个人还款规划工具。以用户从国管住房公积金系统录入的**当前余额**和**当前最低还款额**为测算起点，不声称复刻官方自由还款算法。

## 功能

- 保留安全储备金后计算建议提前还款额
- 提前还款金额实时模拟与两种策略对比
- 月度现金流和储备达标时间测算
- 历史提前还款记录增删
- localStorage 自动保存，以及 JSON 导入、导出

## 本地运行

```bash
npm run dev
```

打开终端显示的地址。项目不需要安装第三方依赖。

## 检查与构建

```bash
npm test
npm run build
```

核心规划计算位于 `src/mortgage.js`，金额逐月按“分”取整。所有结果仅供个人规划，实际数据与规则以国管住房公积金管理中心系统为准。
